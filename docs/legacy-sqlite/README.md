# Historical SQLite implementation

These files and tests preserve the pre-migration implementation for reference. They are not imported or executed by the running Oracle application. The original `atelier/schema.sql` and `docs/SQL_EXPLAINED.sql` also remain unchanged as historical SQL references. Active Oracle DDL, seed, rules and member scripts are under `oracle/`.

Do not use the archived test results as evidence of Oracle behavior. Current execution evidence and transaction verification are under `docs/assignment/`.
